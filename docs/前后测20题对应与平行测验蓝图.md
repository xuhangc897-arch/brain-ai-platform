# 前后测 20 题对应关系与平行测验蓝图

## 平行性验证步骤

1. 已依据上表建立 20 道独立 T5 题，并以 `t5_` ID 与 T0 一一配对；题干、场景和选项内容不同。审题时仍需核查材料长度及选项质量是否相当。
2. 保持两卷相同的模块配额、四选一题型、每题 1 分、总分 20 分及施测条件。答案位置可以重新分布，不应为追求不同而改变题目难度。
3. 请学科教师检查内容覆盖、歧义和干扰项，再用未参与正式实验的同年级学生试测。比较两卷的题目难度、区分度、总分分布与信度，并检查分数对应关系；需要时修订或等值。
4. 完成上述验证后，才能较有根据地称为“平行测验”。仅凭逐题内容对应，仍只能称为“按同一蓝图编制的前后测两卷”。
