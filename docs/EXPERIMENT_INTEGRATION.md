# 教师后台、报告与 AI 整合说明

本文档定义阶段 6 新增的展示与数据适配层。目标是让教师后台、统一报告和 AI 对话记录使用同一套模块识别与记录读取规则，同时保持各自的内容生成和用户交互不变。

## 一、运行时入口

`assets/experiment-integration.js` 暴露只读的：

```text
window.BrainExperimentIntegration
```

它必须在实验注册表和平台核心之后加载，并先于教师后台内联逻辑、`assets/review.js` 和 `assets/ai-assistant.js` 使用。

## 二、公共职责

整合层负责：

- 按模块 ID 读取注册表条目和显示名称。
- 从页面路径识别实验或资格审查模块。
- 规范 AI 对话记录的来源模块。
- 解析报告活动，并保持无效活动回退记忆容量报告。
- 读取数据库记录的 `data` 和 `data.fullState`。
- 按模块 ID 分发教师导出构建器。

整合层不生成报告正文、不转换 Excel 字段，也不读取或修改 AI 问答正文。

## 三、兼容规则

### 报告

- 支持报告的五个实验继续按注册表元数据渲染。
- `screening`、`aiChat` 或未知活动继续回退到 `memory`。
- 报告构建函数、图表、结论和打印布局不变。

### AI

- 调用方传入有效实验或资格审查模块时，保持该模块。
- 来源为空或无效时，按当前页面路径识别。
- 服务模块 `aiChat` 不能作为自己的来源；会按当前页面识别。
- AI 接口请求、消息显示、localStorage 日志和上传调用顺序不变。
- 有效调用的 `clientRecordId` 格式不变。

### 教师后台

- 通用模块名称由整合层读取注册表。
- 数据计数统一读取兼容 payload/fullState。
- Excel 仍调用原来的七个模块构建函数。
- 未知模块仍使用原有记忆容量构建器回退，避免改变历史导出行为。
- 查询条件、CloudBase 请求、表格列和 Excel 内容不变。

## 四、扩展规则

增加模块时：

1. 先更新实验注册表。
2. 如果模块支持报告，增加对应报告构建器。
3. 如果教师后台支持详细导出，增加构建函数并注册到模块分发器。
4. AI 来源只允许注册表中的非服务模块。
5. 增加模块解析、路径识别、报告回退和导出分发测试。

不要在报告、AI 助手或教师后台重新建立模块名称与路径对照表。

## 五、回滚

回滚需要同时恢复整合脚本、报告页、AI 助手、教师后台以及相关页面的脚本引用。本阶段没有改变数据库、localStorage key、AI 日志字段或 Excel schema，不需要数据迁移。
